# Сутності та атрибути

| Сутність             | Атрибути               |
| -------------------- | ----------------------------------------------- |  
| EMPLOYEE | id, first_name, last_name, email, phone |
| STORE | id, name, address |
| ROLE | id, name |
| SHIFT | id, start_time, end_time |
| SHIFT_ASSIGNMENT | id, assigned_at, status |
| SWAP_REQUEST | id, created_at, reason, status |
| AVAILABILITY | id, start_time, end_time |

# Типи даних

| Атрибути             | Тип        |
| -------------------- | ---------- |
| id                 | int      |
| Імена, адреси, назви | string  |
| Телефон та email     | string   |
| Дата й час           | datetime |
| Причина заявки       | string   |
| Статус               | enum    |

# Зв'язки між сутностями

| Сутності | Тип зв'язку | Пояснення |
|---|---|---|
| EMPLOYEE — STORE | M:N | Працівник може працювати в декількох магазинах |
| EMPLOYEE — ROLE | M:N | Працівник може мати декілька ролей |
| STORE — SHIFT | 1:N | Кожна зміна належить одному магазину |
| EMPLOYEE — SHIFT_ASSIGNMENT | 1:N | Працівник може мати багато призначень |
| SHIFT — SHIFT_ASSIGNMENT | 1:N | На зміну можна призначити багато працівників |
| EMPLOYEE — AVAILABILITY | 1:N | Працівник може зазначити декілька періодів доступності |
| SHIFT_ASSIGNMENT — SWAP_REQUEST | 1:N | Заявка стосується призначень, якими працівники хочуть обмінятися |
| EMPLOYEE — SWAP_REQUEST | 1:N | Менеджер може розглядати багато заявок; нерозглянута заявка ще не має відповідального менеджера |

# Критерії прийняття

| Номер | Що має перевіряти критерій                        |
| ----- | ------------------------------------------------------------------- |
| AC-01 | Наявність усіх визначених сутностей та атрибутів            |
| AC-02 | Відповідність зв'язків і кардинальностей бізнес-правилам            |
| AC-03 | Відсутність сполучних сутностей для чистих M:N                 |
| AC-04 | Наявність асоціативної сутності для призначення працівника на зміну |
| AC-05 | Відповідність принципам 1NF, 2NF та 3NF                       |
| AC-06 | Узгодженість назв і типів атрибутів                             |
| AC-07 | Використання Mermaid erDiagram                               |
| AC-08 | Відповідність рендеру декларативному опису                          |
| AC-09 | Відсутність SQL, ORM та деталей фізичної реалізації БД      |
